# UX/UI

## Estilo
SaaS B2B premium, limpio, espacioso, jerarquía fuerte, tarjetas redondeadas, bordes suaves, sombras discretas. No usar Figma como dependencia.

## Ecommerce Builder
No es POS. Layout:
- panel de configuración;
- preview móvil;
- Guardar/Publicar/Ver tienda.

Configurable:
Mi tienda, Apariencia, Portada, Constructor, Catálogo, Carrito, Checkout, Ubicación, Entrega, Pagos, Sucursales, Dominio, Redes, Asistente IA, Configuración.

Preview:
Home → categorías → producto → carrito → checkout → confirmación.

## Pedidos
Módulo independiente:
Todos, Ventas, Reservas, Pendientes, Preparación, Entrega, Rutas del día, Historial.

## Ruta del día
Lista + mapa, pedidos seleccionables, sucursal, responsable, secuencia editable, estado y acciones manuales.

## Navegación
Inicio, Conversaciones, Contactos, Leads, CRM, Flujos, Campañas, Plantillas, IA Agents, Ecommerce, Productos, Pedidos, Promociones, Sucursales, Reservas y Citas, Especialistas, Reportes, Analytics, Configuración.

## Componentes
Button, Input, Select, Badge, Avatar, Card, Table, Modal, Drawer, Tabs, Stepper, Timeline, PhonePreview, SectionBuilder, ColorPicker, ImageUploader, OrderStatus, RouteStopList, MapPanel.

Estados: default, hover, active, focus, disabled, loading, error, empty.
